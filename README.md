# 📧 Spam Message Classifier

## 📌 Overview

This project is a simple Machine Learning application that classifies text messages as Spam or Ham (Normal Message).

The model uses Natural Language Processing (NLP) techniques and a Naive Bayes classifier for prediction.

---

## 🎯 Objective

- Detect spam messages
- Learn text classification
- Understand NLP fundamentals

---

## 🧠 Workflow

```text
Message Input
↓
Text Vectorization
↓
Naive Bayes Model
↓
Spam / Ham Prediction
```


```bash
python predict.py
```
